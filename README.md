# Quadscorer

A compact, installable X01 darts scorer built for phones. It supports standard and Quadro boards, total or dart-by-dart entry, checkout suggestions, undo, visit history, offline use and automatic game restoration.

## Development

```bash
npm install
npm run dev
```

Run the tests and production build with:

```bash
npm test
npm run build
```

The production build is written to `public/`, matching the Forge site's web directory.

See it in action here:
- https://qs.btk.scot
